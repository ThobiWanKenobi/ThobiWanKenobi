# Hi, I'm Thobias

MSc Computer Science student (Programming Languages) at the University of Copenhagen · fullstack engineer at Lenus · working where compilers, high-performance computing, and quantum software meet.

I'm on the Programming Languages track at DIKU, working part-time at Lenus as a fullstack engineer — doing product engineering, including bug-fixing, maintenance, and adding new features across backend and frontend. I like problems where correctness and performance both have to hold at once, and I tend to build the languages and tools rather than just use them — see **Mango** below, a desktop-UI DSL I designed in F# together with some friends I have met online.

### Focus areas
- Language & DSL design, compilers, and program analysis
- GPU and data-parallel computing (CUDA, Futhark)
- Quantum software and hybrid quantum-classical programming
- Functional programming (F#, Haskell) and .NET / C#
- Fullstack Engineering (Typescript, React, PostgreSQL)

### Currently
